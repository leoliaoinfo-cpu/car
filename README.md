# 汽車銷售業務系統

貨車銷售業務（KIA K2500 等）使用的單機版工作系統。主程式在 `assistant/`（React + Vite + Tailwind），資料存在瀏覽器 IndexedDB。系統唯一目的：**不漏追蹤、報價跟得上、成交不掉單**。

手機優先設計：底部導覽、單手可及、核心動作（撥號、記追蹤、標已聯繫）一鍵完成。

## 功能總覽

- **☀️ 今日工作**（預設首頁）：一頁看完逾期/今日追蹤客戶、到期提醒、即將簽約客戶與待辦進度，可直接撥號、標記已聯繫或跳轉客戶詳情。超過 7 天未備份會在此提醒。
- **📅 行事曆**：月曆總覽所有追蹤日期、提醒與成交事件（逾期日期以紅字標示）；點日期看當天事項清單，點事件直接跳到該客戶詳情，追蹤事項可就地標記已聯繫。
- **🌙 莫蘭迪藍灰色調**：全站低彩度藍灰色系，深色為預設（可在設定切換淺色，記憶於裝置）。
- **👥 客戶追蹤 CRM**：新增、搜尋（姓名/電話/LINE ID/備註）、篩選（分類/進度/待聯繫/冷掉了）、排序、置頂；記錄已聯繫、未接電話（達 5 次提示考慮移除）、設定下次追蹤日期。客戶欄位含電話、LINE ID、Email、地址（一鍵開 Google Maps）、來源。「久未聯繫/冷掉了」的天數門檻可在「設定 → 追蹤規則」調整（預設 180 / 365 天）。
- **🚛 業務進度記錄**：客戶時間軸支援 LINE 摘要、報價（含金額）、看車試乘、貸款補件、下訂（含金額）、交車、售後回訪。
- **🔔 交車自動回訪**：記錄「交車」時自動建立交車後 3 / 7 / 30 天的售後回訪提醒，並可勾選建立「保險續保」「驗車到期」年度商機提醒（預設 11 個月後、日期可調）。
- **🎉 紀念日提醒**：自訂欄位的日期型欄位（生日、交車週年…）可設每年重複／一次性／連續 N 年提醒，到期日出現在今日工作（依欄位分組）與行事曆，可一鍵記錄問候。
- **🧾 商用車報價器**：填車型與項目價格，一鍵帶入車體配備（框式/篷式/冷凍廂/尾門…）與政府補助折抵（汰舊換新、貨物稅減免，負數扣抵），選單內容可在「設定 → 報價選單」自訂；內建貸款試算（頭期/期數/利率 → 月付金），可填「這台車每月幫客戶賺多少」自動算出**每月淨賺**——生財工具的說服話術直接印在報價單上。報價單存在客戶檔案可隨時編輯（時間軸金額同步）。
- **🏢 公司戶/個人戶分流**：客戶類型、統編、產業標籤（水電/市場/物流/工程/資收/餐飲…，可搜尋）、多聯絡人（老闆/採購/司機分開存、各自可撥號）。
- **🤝 轉介紹追蹤**：記錄誰介紹誰與介紹金，客戶詳情自動顯示「介紹名單」。
- **🔄 5 年舊換新預測**：交車時自動排入車齡近 5 年的換車評估提醒（預設 4 年半後，日期可調）。
- **📋 中央待辦**：今日工作頁可直接新增/勾銷雜事待辦；所有客戶的簽約前待辦也會集中在「客戶待辦」區逐一處理，點客戶名跳到詳情。交車待辦範本內容可在設定編輯。
- **✏️ 時間軸可編輯**：互動時間軸每筆事件可修改日期、內容、金額，或刪除（兩段確認）。
- **📌 即將簽約**：客戶可置頂、寫重點備註（價格底線、關鍵條件）、管理簽約前待辦清單，可一鍵套用交車待辦範本（保險/貸款對保/驗車領牌/配件/整備）。
- **📊 本日成果**：自動從客戶時間軸統計今天記錄的聯繫/報價/試乘/下訂/交車數量與金額，不需手動填日報。
- **📈 業績表（成交歸檔）**：客戶成交後按「🏆 成交歸檔」帶入當月業績；單月檢視看細項與各欄位加總，總表檢視看歷月全部成交（按月小計＋總計）。金額欄位可自訂（預設：成交金額＋保險金額＋收入），歸檔同時寫入客戶時間軸。
- **⏰ 計時提醒**：到期強制彈窗確認；瀏覽器通知只顯示提醒數量，不含客戶資料。
- **💾 備份還原**：下載 JSON 備份、上傳還原；還原前會檢查格式、顯示摘要，並先自動下載目前資料的備份。支援舊版 `{ _v:1, crm, jnl, sal }` 格式匯入。

預設業務進度採固定管道（可在設定自訂）：

```
新名單 → 已聯絡 → 拜訪中 → 試乘 → 報價 → 議價 → 成交 → 交車 → 售後
```

## 資料模型（IndexedDB：`business_assistant_v2`）

| Store | Key | 主要欄位 |
|---|---|---|
| `clients` | `id` | name, phone, lineId, email, address, source, catId, stageId, intentLevel, notes, nextDate, lastContact, missedCalls, pinned, signingNote, todos[{id,text,done}], log[{id,date,type,text,amount?}], createdAt, updatedAt |
| `cats` / `stages` | `id` | name, colorIdx, order（客戶分類 / 業務進度） |
| `customFields` | `id` | name, type(text/number/date), colorIdx |
| `deals` | `id` | clientId, clientName, date, amount, fields{欄位id:金額}, note（成交歸檔） |
| `dealFields` | `id` | name, colorIdx, order（業績表自訂金額欄位） |
| `journalEntries` / `archivedJournal` / `salaryMonths` | — | 已下架功能的歷史資料，僅為舊備份匯入相容而保留 |
| `timers` | `id` | clientId?, clientName?, note, triggerAt, confirmedAt |
| `settings` | `key` | 例如 `lastBackupAt` |

時間軸事件 `log.type`：`contact / missed / line / quote / visit / loan / order / delivery / aftercare`（quote、order 可帶 `amount`）。

## 本機啟動

需要 Node.js 20+：

```bash
cd assistant
npm ci
npm run dev
```

## 手機測試（LAN 模式）

手機和電腦要在同一個 Wi-Fi：

```bash
cd assistant
npm run dev -- --host --port 5173
```

然後用手機瀏覽器開 `http://電腦區網IP:5173`。如果打不開，通常是防火牆或公司/店內 Wi-Fi 隔離裝置阻擋。

## 建置與部署

```bash
cd assistant
npm run build   # 產出單一 dist/index.html，雙擊即可離線使用
```

Push 到指定分支後，GitHub Actions 會自動建置並部署到 GitHub Pages（見 `.github/workflows/deploy.yml`）。

## 資料與隱私

- 單機版資料存在各自瀏覽器的 IndexedDB；電腦和手機開同一個網址時**資料不會自動同步**，要同步需等雲端版。
- 客戶名單是業務命脈：今日工作頁會在超過 7 天未備份時提醒，請養成定期下載備份的習慣。
- 還原備份會完整覆蓋目前資料；請只匯入本系統匯出的 JSON，且不要把備份檔放在公開雲端連結。
- 通知需要瀏覽器允許權限；部分手機瀏覽器需安裝成 PWA 後才支援通知。
